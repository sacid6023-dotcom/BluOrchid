# Hotel Blu Orchid — React

Premium navy + gold hotel website starter for Hotel Blu Orchid, Moradabad.

## Run
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Notes
- Replace the demo Unsplash images with the hotel's actual professional photos before launch.
- The supplied Blu Orchid logo is already included at `src/assets/logo.png`.
- Contact details are prefilled from the supplied brief.
